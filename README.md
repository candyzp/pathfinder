# Pathfinder
# Geometry Dash Physics Simulator

Pathfinder is an experimental offline Geometry Dash physics simulator and macro pathfinder.

This fork extends the original simulator with modern gameplay support including Dual, Robot, Spider, Swing, dash/spider orbs, modifier blocks, linked teleport portals, modern gravity/time triggers, rotated solids, and expanded upside-down slope handling. See `about.md` for the current support/limitation list.

The simulator is still an approximation of Geometry Dash physics, especially for dynamic 2.2 trigger/group systems, so generated paths should be tested against the real game.

This code is not currently licensed for redistribution.

## Notes

1. Y positions can differ slightly from the real game because Geometry Dash applies additional internal position offsets.
